# Dados de teste

- `standard.epd` (128 posições) e `fischer.epd` (960 posições de Chess960 em Shredder-FEN):
  contagens de perft por profundidade (`;D1 20 ;D2 400 ...`). Copiadas de
  `src/perft/` do [Ethereal](https://github.com/AndyGrant/Ethereal) (GPL-3.0, compatível com a
  licença do Caipora). São os mesmos números publicados pela Chessprogramming Wiki em
  "Perft Results" e "Chess960 Perft Results". São dados de teste (fatos sobre posições de xadrez),
  não código nem parâmetros de engine.
