# AI usage policy

This file states how AI is used in Caipora, so that rating lists, tournaments and anyone reading
the code can judge it with full information.

## Who writes the code

- The code is written by Claude Code (Anthropic's coding agent).
- The author (Matheus de Carvalho Jesus) directs the work, decides what goes in, reviews the
  changes and runs the tests.
- Every commit carries a `Co-Authored-By: Claude` trailer. This trailer is never removed.

## How it is declared

- Rating lists (CCRL, CEGT and others): the engine is announced as "AI assisted" / AI-written.
- TCEC: the questionnaire question about AI-generated code is answered as stated here.
- Lichess: the bot profile links to this file.

## Originality

- Ideas from other engines and from the chess programming literature are used freely and
  credited in the commit or pull request that introduces them.
- Code, constants and tables from other engines are never copied, ported or transliterated,
  regardless of their license.
- Third-party libraries, if any, are listed in the README with their licenses.

## Training data

- Networks up to g3 were trained only on positions generated by Caipora itself (self-play).
- Since 28/09/2026 networks may also be trained on Leela Chess Zero training data, released
  under the Open Database License (ODbL), in the binpack format published by the Stockfish
  community. Every network trained on it says so in its release notes and in the repository's
  decision log. (Until then the policy was self-play only.) The first such network is g4
  (28/09/2026), trained on `test80-mar2023-2tb7p-filter-v6-sk16` only; g5 (30/09/2026) adds
  `test80-jun2023-2tb7p` and `test80-aug2023-2tb7p`.
- No third-party networks are used, as weights or as a starting point.
- The origin of each dataset (which network generated it, how many positions, search limits)
  is recorded in the repository.
